## Important relationship

Control Plane and Development Worker Gateway must remain separate.

Control Plane answers what exists, what it means for a role, what requires attention, and what work should be initiated.

Development Worker Gateway answers where and how approved executable work is run.

This permits the human-facing plane, AI-facing projections, and execution infrastructure to evolve independently.
